# Допоміжні скрипти

`get_hh_token.ps1` — попередній помічник отримання токена офіційного HH API.
Поточний HTML-збирач `hh_fast.py` його не використовує й токена не потребує.
Токен зберігається лише у змінній середовища цього PowerShell-сеансу;
облікові дані не записуються у файли.

Старий запуск із кореня збережений:

```powershell
powershell -NoExit -ExecutionPolicy Bypass -File .\get_hh_token.ps1
```

Основні команди збору й розширення вибірки описані у кореневому README.
Одноразові дослідницькі скрипти й результати експериментів залишаються у
`tmp/`; вони не є частиною регулярного запуску.
